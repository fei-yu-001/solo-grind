# 截图操作指南

> 用途：按这份指南逐张截图，替换实验报告里的虚线占位框。
> 工具：IntelliJ IDEA（后端）、VS Code（前端）、Navicat（数据库）、Postman（接口）、Chrome（页面）、PowerShell（命令行）。
> 截图统一存到 `交付\截图\`，文件名直接用报告里的图号，例如 `图4-1-后端工程结构.png`。

---

## 一、截图前统一设置（很重要）

1. **分辨率与缩放**：Windows 显示缩放设为 100%，浏览器缩放 100%（Ctrl+0）。截图宽度建议 1600px 以上，保证报告里字不糊。
2. **窗口大小**：IDEA 最大化；浏览器窗口拉宽到 1600×900 左右，避免表格横向滚动条。
3. **隐藏敏感信息**：数据库密码、API Key、token 不要出现在截图里。Navicat 连接名改成 `zhikao`，不要显示密码；Postman 的 Authorization 只显示 `Bearer ••••`。
4. **统一深色/浅色**：IDEA 用浅色主题（报告是白底）；浏览器用默认浅色。
5. **截图方式**：Win + Shift + S 区域截图，或 Alt + PrintScreen 截当前窗口。保存 PNG，不要用 JPG（表格文字会糊）。

## 三、Navicat 截图（数据库）

### 3.1 连接与打开库
1. 新建 MySQL 连接：主机 `127.0.0.1`，端口 `3306`，用户名 `root`，密码填自己的。
2. 连接名写 `zhikao`，双击打开，展开数据库 `zhikao`。

### 3.2 表结构（图 4-2）
1. 左侧展开 `zhikao → 表`，让 9 张表全部可见。
2. 双击 `user_profile` 打开数据视图。
3. 截图范围：左侧表列表 + 右侧数据网格（能看到 school、group_name、phone 三列）。

### 3.3 多表查询（图 6-15）
1. 工具栏点 **新建查询**。
2. 粘贴下面 SQL 并点运行：

```sql
SELECT ar.paper_id, p.title, u.nickname,
       SUM(ar.score)                            AS totalScore,
       SUM(ar.correct = 1)                      AS correctCount,
       SUM(ar.chosen IS NULL)                   AS blankCount,
       ROUND(SUM(ar.correct = 1) / COUNT(*), 2) AS accuracy
FROM answer_record ar
JOIN exam_paper p ON p.id = ar.paper_id
JOIN sys_user  u ON u.id = ar.user_id
GROUP BY ar.paper_id, ar.user_id, p.title, u.nickname
ORDER BY ar.paper_id, totalScore DESC;
```

3. 等结果网格出来（应有 3 行：92、68、84）。
4. 截图范围：上半部分是 SQL 编辑区，下半部分是结果网格。

### 3.4 表关系图（可选加分）
Navicat 菜单 `工具 → 逆向数据库到模型`，选 zhikao，会自动生成关系图，可以再截一张替换报告里的 E-R 图（如果老师更喜欢工具生成的）。

## 四、Postman 截图（接口测试）

### 4.1 先拿 token
1. 新建 Collection，命名 `赛博进京赶考`。
2. 新建请求 `POST http://127.0.0.1:8080/api/auth/login`。
3. Body 选 raw → JSON，填：

```json
{ "username": "admin", "password": "admin123" }
```

4. Send，从返回里复制 `data.token`。

### 4.2 设置 Bearer Token
在 Collection 的 Authorization 标签选 **Bearer Token**，把 token 粘进去。之后所有请求继承这个 token，不用每个都填。

### 4.3 各图怎么拍

| 图号 | 请求 | 要拍到的内容 |
|---|---|---|
| 图 6-3 | POST /api/auth/login | 请求体、返回 200、data.token、role=ADMIN |
| 图 6-4 | GET /api/banks?page=1&size=10 | URL 参数、Authorization 显示 Bearer、返回分页数据 |
| 图 6-5 | GET /api/banks（Authorization 设为 No Auth） | 返回 401 和「登录已失效，请重新登录」 |
| 图 6-6 | POST /api/banks（用 student01 的 token） | 返回 403 和「无权限，仅管理员可操作」 |
| 图 6-18 | POST /api/answers/submit 同一试卷交两次 | 第二次返回 409 和「同一考生同一试卷只能交一次卷」 |
| 图 4-4 | GET /api/questions/999999 | 返回 404 和「题目不存在」 |

拍的时候把 **Status、Time、Size** 三个数字带上，证明是真实请求。

## 八、把截图放进 Word

报告里每个图位是一个**虚线框**，里面写着「【此处插入截图：xxx】」。两种替换方式：

**方式一（推荐）**
1. 点一下虚线框，光标进入单元格。
2. 删除框里的占位文字（保留空单元格）。
3. 菜单 `插入 → 图片 → 此设备`，选对应 PNG。
4. 图片宽度设为 **14 厘米**（右键图片 → 大小和位置 → 宽度 14 cm，锁定纵横比）。
5. 虚线框还在的话，选中表格 → 边框 → 无框线，把虚线去掉。

**方式二**
1. 选中整个虚线框表格，按 Backspace 删除。
2. 在原位置 `插入 → 图片`。
3. 图片下方手动补图注（宋体 10.5 磅、居中），格式如「图 4-1 后端工程结构」。
